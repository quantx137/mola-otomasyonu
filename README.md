# Kuaför Site Tasarımcısı

Kuaförlere satış sırasında canlı demo göstermek için tek sayfalık tasarım seçici.
Build/kurulum yok: `index.html` dosyasını tarayıcıda açmanız yeterli (veya GitHub Pages / Netlify'a yükleyin).

## Özellikler
- Salon adı, slogan, telefon, adres, şehir, Instagram → anında önizleme
- Salon türü: Erkek / Bayan / Unisex (hizmet listesi ve metinler değişir), fiyat göster/gizle
- 3 şablon: Klasik, Modern, Lüks
- 7 hazır renk paleti + özel renk seçici
- Fotoğraf yükleme (yalnızca cihazda, linke eklenmez)
- **Tam Ekran Göster**: paneli gizler, müşteriye sadece siteyi gösterir
- **Linki Kopyala**: tüm ayarlar URL'de saklanır; linki kuaföre WhatsApp'tan gönderebilirsiniz
- WhatsApp randevu butonu, arama butonu, Google Maps haritası

## Dosyalar
- `index.html` – panel + önizleme iskeleti
- `style.css` – panel ve 3 şablonun stilleri
- `app.js` – veri (paletler, hizmetler), render, URL paylaşımı
